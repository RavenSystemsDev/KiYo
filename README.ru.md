# KiYo

Приложение для macOS от [Raven Systems](https://ravensystems.io/), которое исправляет текст в неверной русской или английской раскладке и переключает язык ввода.

## Возможности

Автоматическая смена RU/EN, отдельная проверка орфографии macOS, исключения, произвольные горячие клавиши для исключений и исправления раскладки выделенного текста, чёлка или строка меню, ручная правка ⌃⌥Пробел, пауза, автозапуск по выбору пользователя, русский и английский интерфейс, синхронизация настроек через выбранную папку iCloud Drive.

Написание имени приложения приводится к KiYo. Слитный русский ввод проверяется общим правилом разбиения на несколько слов по системному словарю, а не таблицей фраз. Для каждого количества слов требуется однозначный вариант; время проверки ограничено. Одиночные буквы автоматически не меняются. Если сразу полностью стереть исправленное слово клавишей Backspace и набрать заново, KiYo сохранит только ближайшую повторную попытку в течение 15 секунд, не добавляя его в постоянные исключения.

Обратная связь из настроек: письмо об ошибке или предложении на dev@ravensystems.io, которое отправляет сам пользователь.

## Сборка

Нужен Mac на Apple Silicon с macOS 13+ и инструментами разработчика Apple. Для проверки публикации нужен Python 3. Реальная проверка текущего поведения выполнена на macOS 26.6.2; другие версии требуют проверки.

```sh
./build.sh
./scripts/test.sh
python3 scripts/audit-public.py
```

Результат: `dist/Kiyo.app`. По умолчанию используется временная подпись для локальной разработки. Ключи, пароли и сертификаты автора не нужны и не поставляются. Скрипт не меняет системное доверие сертификатам. Для публичного релиза нужны Developer ID и нотариализация Apple. Не отключайте Gatekeeper и не заменяйте установленный официальный релиз своей сборкой без необходимости: разрешение Accessibility может потребоваться повторно.

Сборка DMG: `./scripts/package-dmg.sh`.

## Использование и ограничения

Разрешите «Универсальный доступ» в настройках macOS и добавьте русскую и английскую раскладки. Орфография включается отдельно. В настройках «Добавить выделение» нажмите сочетание и задайте своё; стандартное — ⌃⌥K. Выделите слова и нажмите его, чтобы добавить их в исключения. «Исправить выделение» (⌃⌥R) меняет раскладку целого выделенного текста; это сочетание настраивается отдельно.

Система не гарантирует распознавание любой опечатки или работу в каждом стороннем редакторе. Защищённый ввод и распознанные поля паролей/email пропускаются. Не вносите секреты в исключения.

Набираемый текст не отправляется разработчику. Исключения и настройки сохраняются локально; по желанию синхронизируются через выбранную папку. Разрешения и автозапуск остаются отдельными на каждом Mac. Получение выделения иногда временно использует буфер обмена с попыткой восстановления прежних форматов.

Тесты не отправляют события в macOS и используют отдельные хранилища настроек. Проверка физического ввода, реального входа в систему и двух Mac выполняется отдельно.
