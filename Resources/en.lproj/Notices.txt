Developer: Raven Systems — https://ravensystems.io/

No third-party packages, dependency manifests or bundled third-party SDKs were found in the reviewed project tree. The app is written in Swift and uses Apple's system frameworks: AppKit, Foundation, Carbon, ApplicationServices, QuartzCore and ServiceManagement. macOS provides spelling dictionaries and suggestions; their contents are not copied into the app.

Technology names in the built-in word list are text used for keyboard-layout recognition. KiYo does not include the code of those products.

The KiYo panel logo uses a monochrome PNG with a transparent background. The interface uses system SF Symbols and macOS fonts; system font files are not distributed separately. The raster app icon is included as AppIcon.icns.
