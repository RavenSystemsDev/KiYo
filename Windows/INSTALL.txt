KiYo for Windows 0.1.0-alpha.7 — Raven Systems

ENGLISH
Windows 11. Open KiYo-Setup.exe and click Install.
The installer automatically chooses Intel/AMD x64 or ARM64. .NET is included;
no download, SDK or administrator access is needed. If downloaded from GitHub
Actions, extract its ZIP first; it contains the installer and a checksum file.
Use Installation options to choose a folder or add a desktop shortcut.
Close KiYo before updating. Uninstall from Windows Settings > Apps > KiYo.
Settings and exclusions are preserved when updating or uninstalling.
Advanced portable ZIP: extract ALL files, then run KiYo.exe in that folder.
Look for KiYo beside the clock (possibly under the hidden-icons arrow).
Double-click the icon for Settings; right-click for Pause and Quit.
Enable English (United States) and Russian keyboards in Windows Settings.

Type ghbdtn followed by space using the English layout. In a supported editor
with accessible editable text and an unchanged caret, KiYo converts it to привет.
With Russian selected, physical h and i produce рш, corrected to hi after a space.
Ctrl+Alt+R converts selected text; Ctrl+Alt+K adds selected words to exceptions.
Change both shortcuts in Settings. Launch at login is optional and off initially.
Disable it before moving/deleting the portable folder.

Enable Spelling correction in Settings to fix typos after a space. It is off by
default and uses installed Windows language dictionaries. Ambiguous suggestions,
excluded words and protected fields are skipped. Install Russian Basic typing
features if the Russian dictionary is missing.

Alpha limitations: no Authenticode signing, no automatic updater or iCloud sync.
Windows dictionaries also help detect layout mistakes. Fast typing
keeps completed words pending and retries the latest text after a short pause;
the unfinished next word is preserved. The pending suffix is limited to 1024
characters and expires after two idle seconds. Unsupported,
protected, read-only, elevated and remote/custom editors may be skipped. KiYo
does not elevate itself or bypass Windows restrictions. This build needs physical
keyboard acceptance testing on Windows before it is called stable.

RUSSIAN
Windows 11. Откройте KiYo-Setup.exe и нажмите «Установить».
Установщик сам выберет версию для Intel/AMD или ARM; .NET уже внутри.
Если скачали архив GitHub Actions — сначала распакуйте его: внутри установщик
и файл контрольной суммы. Устанавливать .NET отдельно не нужно.
«Параметры установки» позволяют выбрать папку и ярлык рабочего стола.
Перед обновлением закройте KiYo. Удаление: Параметры Windows > Приложения > KiYo.
Настройки и исключения сохраняются при обновлении и удалении.
Для переносного ZIP: распакуйте ВЕСЬ архив и запустите KiYo.exe из его папки.
Значок появится возле часов, иногда под стрелкой скрытых значков.
Двойной щелчок — настройки; правая кнопка — пауза и выход.
Добавьте английскую (США) и русскую раскладки в настройках Windows.

ghbdtn + пробел → привет. рш + пробел → hi.
Ctrl+Alt+R — исправить выделенный текст; Ctrl+Alt+K — добавить в исключения.
Сочетания настраиваются. Автозапуск включается по желанию.
Перед переносом или удалением папки отключите автозапуск.

Это alpha-версия: требуется проверка физическим вводом на Windows.
При быстром вводе завершённые слова сохраняются для повторной проверки.
После короткой паузы исправляется накопленный фрагмент; недописанное слово
сохраняется. Буфер ограничен 1024 символами и очищается после двух секунд простоя.
Перемещение курсора и недоступные поля отменяют правку.
Для опечаток включите «Исправление орфографии» в настройках и сохраните.
Исправление срабатывает после пробела, использует установленные словари Windows
и по умолчанию выключено. Неоднозначные варианты и исключения пропускаются.
Если русского словаря нет, добавьте компонент «Базовый ввод» для русского языка
в настройках Windows. Синхронизация пока не перенесена.
Сборка не подписана Authenticode; не отключайте защиту Windows.
